# SkinRadar — сайт

Статический лендинг и кабинет SkinRadar: поиск дешёвых скинов CS2 по пяти площадкам.

- Приложение (приватный репозиторий): https://github.com/systemAdmin-ai/skinradar
- API: https://skinradar-api.notchdeck.workers.dev
- Сайт: https://systemAdmin-ai.github.io/skinradar-site/

Пароль Steam не запрашивается. Пароли пользователей хранятся только как хеш PBKDF2-SHA256.
